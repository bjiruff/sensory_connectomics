# Overview
This project is meant to characterize the flow of sensory information in the *Drosophila melanogaster* connectome, which is a directed graph where nodes are neurons and edges are synaptic connections. Three datasets are able to be utilized, including FAFB (female brain), MCNS (male brain + nerve cord), and MANC (male nerve cord). All results below were created using FAFB v783. The original goal of this project was to find which sensory modalities are responsible for controlling octopaminergic neurons, a diverse group of cells that drive behaviors such as aggression and feeding. Leveraging connectomics, the idea was to generate hypotheses on how octopaminergic neurons integrate information from multiple sources

# Analysis
## Orders from sensory layers
The "order" of a neuron refers to its distance from the sensory layer, where sensory neurons are "1st order", their downstream neurons are "2nd order", and so on. We use a breadth first search to assign orders to cells, effectively meaning cell's order is its shortest path distance in hops from the sensory layer. Although in reality cells are not really organized into discrete layers, we still find this approach to be useful for comparing how different sensory modalities are topologically organized.

The visual layer accesses the most amount of cells early on compared to every other modality, probably because the visual modality's sensory layer contains significantly more cells than that of any other modality. Nevertheless, number of cells in the sensory layer does not fully predict expansion speed. The thermosensory and olfactory layers contain 29 and 2281 cells respectively, but these modalities expanded at similar trajectories. All modalities saturate the connectome by orders 6-7. All modalities reach the majority of cells in the brain by order 4, highlighting the small-world nature of the connectome.

Using jaccard similarity to compare the sets of cells in each order relative to each modality's sensory layer, we observe that these sets have little overlap in earlier layers but become similar in later layers. These results suggest that sensory computations act on independent pathways at first, but these pathways converge as information travels into deeper and higher order areas of the brain. Eyeballing it, it appears that gustatory, thermosensory, hygrosensory, and olfactory processing cluster by orders 3 and 4. Mechanosensory and auditory processing also cluster somewhat. Meanwhile, the visual modality appears to access largely distinct pathways from every other modality.

Here, we only picture orders 3 and 4 as these provide a nice point of comparison among the modalities. These heatmaps depict how many neurons belong to each cell class for each order. One thing to note is that the visual modality prior to order 4 reaches relatively few cells outside of the optic lobes, showing that central brain regions generally access visual information in a processed instead of a direct, pure form. ### Earlier orders send feedforward connections, later orders send feedback connections
<img width="4050" height="1800" alt="fafb_synapse_flow_per_modality" src="https://github.com/user-attachments/assets/7c933849-5a4a-4272-86ac-d49612fb25bd" />
Here, for the cells in each order, we calculate the proportion of synapses sent to later orders (feedforward), the same order (lateral), and earlier orders (feedback). As expected, we see a general trend across all modalities where the early orders (1 and 2) send primarily feedforward connections, functioning to project sensory information to higher order centers. Intermediate orders such as orders 3 and 4 transition into making many lateral and some feedback connections, performing internal computations to process sensory information. The later orders (5 and 6) send more feedback synapses, suggesting that higher orders serve a more regulatory role. It is subtle, but some modalities seem to make the transition from feedforward to feedback faster than others, particularly the visual, mechanosensory, and auditory modalities. Although, it is difficult to say if this is meaningful since this trend could just be a result of anatomical scale, given that the visual and mechanosensory sensory layers have many more cells compared to other modalities. 

## Sensory preferences of cell types
As mentioned in the overview, the original purpose of this project was to characterize the sensory preferences of octopaminergic cells. As an attempt to answer this question, we developed a deterministic diffusion model where sensory information is iterativel
At each step, a node's "sensory proportion" for a given modality is computed as the weighted sum of its upstream inputs' proportions, where weights are each input synapse's fraction of the upstream node's total input. Nodes are cell types instead of individual neurons to make the model and results more tractable.
The image below outlines an example of the diffusion model for the first 4 iterations on a small network. The numbers inside the nodes represent their "sensory proportions":

We then asked if octopaminergic cell types receive more sensory drive from any modality than can be expected by chance. To answer this question, we created "null connectomes" with randomized sensory connections to 2nd order cells. This was achieved by performing random edge swaps among sensory cells. And we compared the results of running our diffusion model on the null connectomes versus the actual connectome.
