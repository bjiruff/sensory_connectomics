# Overview

This project is meant to characterize the flow of sensory information in the *Drosophila melanogaster* connectome, which is a directed graph where nodes are neurons and edges are synaptic connections. Three datasets are able to be utilized, including FAFB (female brain), MCNS (male brain + nerve cord), and MANC (male nerve cord). All results below were created using FAFB v783. The original goal of this project was to find which sensory modalities are responsible for controlling octopaminergic neurons, a diverse group of cells that produce behaviors such as aggression and feeding. Leveraging connectomics, the idea was to generate hypotheses on how octopaminergic neurons integrate information from different sensory sources when driving behavior.

# Analysis

## Orders from sensory layers
The "order" of a neuron refers to its distance from the sensory layer, where sensory neurons are "1st order", their downstream neurons are "2nd order", and so on. We use a breadth first search to assign orders to cells, effectively meaning cell's order is its shortest path distance in hops from the sensory layer. Although in reality cells are not really organized into discrete layers, we still find this approach to be useful for comparing how different sensory networks are topologically organized.

The visual layer accesses the most amount of cells early on compared to every other modality, probably because the visual modality's sensory layer contains significantly more cells than that of any other modality. Nevertheless, number of cells in the sensory layer does not fully predict expansion speed. The thermosensory and olfactory layers contain 29 and 2281 cells respectively, but these modalities expanded at similar trajectories. All modalities saturate the connectome by orders 6-7. All modalities reach the majority of cells in the brain by order 4, showcasing the small-worldness of the connectome.

Using jaccard similarity to compare the sets of cells in each order relative to each modality's sensory layer, we observe that these sets have little overlap in earlier layers but become similar in later layers. Eyeballing it, it appears that gustatory, thermosensory, hygrosensory, and olfactory processing cluster by orders 3 and 4. Mechanosensory and auditory processing also cluster somewhat. Meanwhile, the visual modality appears to access largely distinct pathways from every other modality.

### Earlier orders send feedforward connections, later orders send feedback connections
<img width="4050" height="1800" alt="fafb_synapse_flow_per_modality" src="https://github.com/user-attachments/assets/7c933849-5a4a-4272-86ac-d49612fb25bd" />
Here, for the cells in each order, we calculate the proportion of synapses sent to later orders (feedforward), the same order (lateral), and earlier orders (feedback). As expected, we see a general trend across all modalities where the early orders (1 and 2) send primarily feedforward connections, functioning to project sensory information to higher order centers. Intermediate orders such as orders 3 and 4 transition into making many lateral and some feedback connections, performing internal computations to process sensory information. The later orders (5 and 6) send more feedback synapses, suggesting that higher orders serve a more regulatory role. It is subtle, but some modalities seem to make the transition from feedforward to feedback faster than others, particularly the visual, mechanosensory, and auditory modalities. Although, it is difficult to say if this is meaningful since this trend could just be a result of anatomical scale, given that the visual and mechanosensory sensory layers have many more cells compared to those of other modalities. 

## Sensory preferences of cell types

As mentioned in the overview, the original purpose of this project was to characterize the sensory preferences of octopaminergic cells. As an attempt to answer this question, we developed a deterministic diffusion model where sensory information is iteratively propagated propagated across the connectome from primary sensory neurons through their downstream partners, until each cell type's mixture of sensory inputs stabilizes. At each step, a node's "sensory proportion" for a given modality is computed as the weighted sum of its upstream inputs' proportions, where weights are each input synapse's fraction of the upstream node's total input. The model is run until sensory proportions converge. Nodes are cell types instead of individual neurons to make the model easier to interpret.
The image below outlines an example of the diffusion model for the first 4 iterations on a small network. The numbers inside the nodes represent their "sensory proportions". Intially, sensory cells of a certain modality are set to have a sensory proportion of 1.0 (meaning 100% of their output is sensory information) while all other cells are set to 0.0:
<img width="644" height="436" alt="Weighted sensory input example" src="https://github.com/user-attachments/assets/685ac23e-cdb4-4110-9d32-124b6ef3c33c" />
The diffusion model is run for each sensory modality separately, resulting in sensory proportions for each cell type for each modality. We then asked if octopaminergic cell types receive more sensory drive from any modality than can be expected by chance. To answer this question, we created "null connectomes" with randomized sensory connections to 2nd order cells. This was achieved by performing random edge swaps among sensory cells. Then, we compared the results of running our diffusion model on the null connectomes versus the actual connectome.

### SMP142 receives information from multiple sensory modalities 
<img width="3600" height="1800" alt="fafb_SMP142_sensory_null_comparison" src="https://github.com/user-attachments/assets/e9a2e9ab-7a0e-4832-b617-72e99b7ada9d" />
SMP142 is a possible octopaminergic cell type known to suppress aggressive behaviors upon activation. Nevertheless, the sensory channels responsible for modulating SMP142 are unknown. Blue distributions represent sensory inputs to SMP142 under 1000 null connectomes while the red lines represent SMP142's actual sensory input. P-values are calculated with p = (1 + #null >= observed) / (1 + n), and from these we get Benjamini-Hochberg-adjusted q-values. Because SMP142 is located in superior medial protocerebrum, a region close to the mushroom body, this cell type is probably primed to receive olfactory information. Indeed, we see that SMP142 receives statistically significant olfactory inputs. The cell type also receives significant thermosensory and hygrosensory inputs, which makes sense as these two modalities access similar pathways as the olfactory modality. More notably, SMP142 gets significant auditory drive, highlighting the possibility that auditory pathways are able to modulate SMP142's activity. Overall, we can see how our method allows us to generate hypotheses on the sensory preferences of specific cell types in the fly brain.

### Octopaminergic cell types are multimodal
<img width="3420" height="4950" alt="fafb_pvalue_heatmap" src="https://github.com/user-attachments/assets/32e358c6-8f6f-401a-aee6-4215430de473" />
Running significance tests on all (confirmed and tentative) octopaminergic cell types, we can see that all of them receive statistically significant inputs from at least two sensory modalities, providing evidence that octopaminergic neurons serve an integrative role by acting as points of convergence for a diverse array of sensory channels. The most frequently significant modalities appear to be the olfactory, thermosensory, hygrosensory, and auditory modalities, highlighting that these sensory classes may be particularly important for driving aggression, mating, other behaviors associated with octopamine.

### Modality-specific cell types cluster into expected classes
<img width="3000" height="1800" alt="fafb_significant_types_per_class" src="https://github.com/user-attachments/assets/2bc36f53-65e7-411a-9f24-39a923ca879d" />
As a sanity check to make sure that our model is not producing spurious findings, we counted the number of cell types with statistically significant sensory drive across each class annotation, comparing the results with what is known about the sensory preferences of each class. Classes that begin with "AL" belong to the antennal lobe, a region of the central brain that receives input from the fly's antennae, which are dense in olfactory, thermosensory, and hygrosensory neurons. Antennal lobe neurons are known to have significant projections to higher order centers like the mushroom bodies and the lateral horn (these cells with class names that begin with "MB" and "LH"). As Kenyon cells are located in the mushroom body, they also receive many inputs from the antennal lobe. All of this is to say that classes that begin with "AL", "MB", "LH", and "Kenyon_Cell" should be rich in olfactory, thermosensory, and hygrosensory processing. Indeed, we can see that the majority of cell types in all of these classes had statistically significant olfactory, thermosensory, and hygrosensory drive. It also makes sense that DANs (dopaminergic neurons) significantly cluster with these three modalities too, since DANs are close to the mushroom body and are known to be important for olfactory learning. Optic lobe cells are obviously visual processing, and indeed we see that they almost exclusively cluster with the visual modality.

Counting the number of cell types that receive significant inputs from one or more modalities, we can see that the majority of cell types merge inputs from multiple modalities. There were no cell types that were significant for all 7 modalities analyzed here. These results point to the idea that most cells in the fly brain feature non-random pathways from multiple sensory sources, priming cells to integrate different kinds of sensory information. Nevertheless, there were certain modalities that tended to cluster together. Looking at the biggest slices in each pie chart, we can see that, as expected, combinations such as olfactory+thermosensory+hygrosensory and mechanosensory+auditory were frequent. More interesting combinations include 529 cell types that were significant for visual+auditory and 139 cell types that were significant for thermosensory+hygrosensory+auditory. Unexpected modality pairings like these were not uncommon, suggesting that multisensory integration in the fly brain isn't confined to modalities that are anatomically or ecologically related, pointing to a broader capacity for multimodal integration in the fly brain than a modality-segregated model would predict.
